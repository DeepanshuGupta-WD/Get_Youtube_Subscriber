    Guidelines for building it
    
        
    Databases sit behind almost every app. With MongoDB, a document database made for high-volume data, you can add, read, update and delete records. This task covers the read side with three endpoints.
    

        
    
          
    
            
    Set it up
    
            
      
              
    1. 
                
      Install MongoDB on your computer and make sure it is running.
      
              
      2. 
              
    2. 
                
      Install the project's packages.
      
                
      npm install
      
              
      3. 
              
    3. 
                
      Create the database with sample subscribers.
      
                
      node src/createDatabase.js
      
              
      4. 
              
    4. 
                
      Start the server, then open http://localhost:3000.
      
                
      node src/index.js
      
              
      5. 
            
    
          
    

          
    
            
    Follow these rules
    
            
      
              
    • app.js only handles requests and responses.
      • 
              
    • Connect to MongoDB and start the server in index.js or another file, not in app.js.
      • 
              
    • Return status 400 and { message: error.message } when the ID does not match.
      • 
              
    • Define /subscribers/names before /subscribers/:id, so "names" is not read as an ID.
      • 
              
    • Do not modify src/models/subscribers.js, src/createDatabase.js or src/index.js. They are there to help you, so read them once.
      • 
            
    
          
    
        
    

        
    
          
    Endpoints
    
          
    
            GET
            /subscribers
            
    An array of subscribers, each one an object.
    
          
    
          
    
            GET
            /subscribers/names
            
    An array of objects with only two fields: name and subscribedChannel.
    
          
    
          
    
            GET
            /subscribers/:id
            
    The subscriber with that ID. If the ID does not match, status 400 and { message: error.message }.
